# Сверка с оригинальным PDF

Источник: `6. ИТ Школа Ростелекома.pdf`, 9 физических страниц (титул + 8 страниц текста). Полный текст сохранён в pdf-text.txt. PDF перечитан при проектировании и перед сдачей. Дополнительные инструкции расширяют исходное задание и не отменяют его требований. Роль «менеджер по ВУЗам / КАМ» соответствует USER, «руководитель» — MANAGER.

Обозначения: [x] реализовано и проверено доступным способом; [ ] остаётся проверка/внешнее действие. Ограничения явно перечислены, отсутствие Docker Engine не считается успешным контейнерным запуском.

- [x] Период, ВУЗ, направление, программа, продукт, ответственный и этап в фильтрах.
- [x] Статистика/графики на данных БД и экспорт диаграммы PNG/PDF.
- [x] Визуализация пути, переходы, переименование этапов, комментарии переходов и история.
